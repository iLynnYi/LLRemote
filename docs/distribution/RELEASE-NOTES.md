# LL Remote 1.0.0

这是 LL Remote 的首个公开版本。你可以在内网连接另一台电脑，查看画面并用键盘和鼠标操作，也可以共享自己的桌面。

## 可以做什么

- 保存和分组管理常用电脑，同时打开多个远程会话。
- 在独立窗口查看远端画面，保存截图或录制无声视频。
- 远端支持时，可以同步剪贴板、上传文件和切换显示器。

## 下载和安装

- macOS 需要 15 或更新版本。请按 Apple 芯片或 Intel 芯片选择安装包。共享屏幕时需要屏幕录制权限，让对方操作键鼠还需要辅助功能权限。
- Windows 需要 Windows 10 1809 或更新版本。请选择与系统类型一致的 x64、x86（32 位）或 ARM64 安装包。安装系统共享服务需要管理员授权。

请在发布页查看可下载的安装包、SHA-256 校验值及签名说明。安装后可在“设置 → 关于”离线查看安装说明和隐私说明。

## 使用前了解

- 远程连接当前不加密，请在可信内网或加密通道中使用。
- 文件目前只能上传。能否操作锁屏或管理员授权界面，取决于远端系统和共享方式。
- 更新版本请从发布页下载。
