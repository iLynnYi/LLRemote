# 安装、升级与卸载

本说明适用于 LL Remote 1.0.0。请从发布页下载与电脑匹配的安装包。发布页会列出每个文件的 SHA-256，也就是用来核对下载文件的校验值。

## 在 Windows 上安装

需要 Windows 10 1809 或更新版本。安装包分为 x64、x86（32 位）和 ARM64。请按 Windows 的系统类型选择。即使系统可以模拟运行其他类型的程序，安装也要求安装包与系统类型一致。

打开文件名以 `-setup.exe` 结尾的安装包，按需要选择安装方式。

- **仅为我安装**是默认选项。首次安装时无需管理员授权，可以连接远端，也可以在登录后共享这台电脑。
- **为所有人安装**供这台电脑上的多个账户使用。只有管理员账户可以选这一项，选中后需要确认 Windows 的授权提示。安装程序会准备系统共享服务。首次使用时，在“本机共享”完成设置并开始共享。

安装包自带应用需要的 WebView2。电脑上缺少它时，安装程序会从包内安装，无需提前下载。安装完成时，可以分别选择是否打开 LL Remote 和创建桌面快捷方式。

安装失败时，先按弹窗提示处理。如果提示需要修复，请保留原安装目录和其中的恢复文件，重新运行同一版本或更新版本的安装包。

## 在 macOS 上安装

需要 macOS 15 或更新版本。请根据电脑使用的 Apple 芯片或 Intel 芯片选择安装包。

1. 如果下载的是 ZIP，先解压，再打开其中的磁盘映像（DMG）。
2. 将 LL Remote 拖到“应用程序”，从“应用程序”打开它。
3. 如需共享这台 Mac，打开“本机共享”，按页面提示为“LLRemote Service”授予屏幕录制权限。要让对方操作键盘和鼠标，还需授予辅助功能权限。

如果 macOS 提示无法验证开发者，请核对下载来源、发布页上的校验值和签名说明。更新或移动应用后，若共享提示权限不足，请按“本机共享”中的提示重新授权，再点击“重新检测”。

## 连接和共享

- **连接另一台电脑**。在“主机”里添加对方的地址和 VNC 端口，双击主机卡片连接。需要密码时按提示输入，可以自行选择是否保存。
- **共享这台电脑**。打开“本机共享”，按提示设置地址、端口和访问密码，再点“开始共享”。用完请点“停止共享”。退出主程序后，共享后台仍能继续运行。
- **选择 Windows 共享方式**。只在登录后共享桌面，可以选“直接开始共享”。如果需要在登录界面或锁屏时连接，可以在“设置 → 本机共享”选择“安装服务并开始共享”。按提示输入共享密码并完成管理员授权。切换共享方式可能断开当前连接。实际可操作的画面取决于 Windows 的设置和权限。
- **共享遇到问题**。Windows 可在“设置 → 本机共享”点“检测并修复”，按结果处理。若提示“普通共享 · 临时兜底”，本次使用登录后的普通共享。macOS 可按提示“更新并修复共享后台”，然后重新检测权限。更新共享后台会断开当前连接。

剪贴板、上传文件和切换显示器取决于远端支持的功能。远程连接当前不加密，请在可信内网、可信 VPN 或加密隧道里使用，避免把共享端口直接开放到互联网。

## 升级或修复

1. 备份前请停止共享、断开会话，再退出 LL Remote。主机列表、设置和文件的位置见“数据与隐私”。保存的密码由系统单独保管，从备份恢复时可能需要重新输入。
2. Windows 运行新安装包，沿用原来的安装方式和目录。已有系统共享服务时，更新可能需要管理员授权。升级会保留个人设置和保存的密码，共享停止后需要手动重新开始。
3. macOS 将新版应用拖到“应用程序”并替换旧版。打开后按提示更新共享后台并检查权限。
4. 启动新版，确认常用主机、共享设置和一次实际连接都正常。

Windows 若要改为另一种安装方式，请先备份，再卸载原安装并重新选择。应用会阻止直接使用较低版本打开新版本的数据。回退前请准备与目标版本兼容的备份。

## 卸载和清理数据

先停止共享、关闭自动共享，再断开会话和退出应用。

### Windows

在系统的“已安装的应用”中卸载 LL Remote。卸载确认页会显示要处理的账户。个人安装以安装该应用的账户为准，整机安装以最先发起卸载的账户为准。输入另一位管理员的密码进行授权时，确认页上的清理对象保持不变。

- **普通卸载**会移除应用，停止目标账户的共享后台并关闭登录自启动。个人设置和保存的密码会保留。
- **勾选“同时删除上述用户的设置、缓存和保存的密码”**会额外清理目标账户的主机记录、偏好、目录授权、传输记录、共享设置、默认日志及该账户保存的密码。
- **截图、录制和接收的文件会保留**，包括保存在应用默认目录中的文件。自行指定的日志位置等目录也请按需要检查。
- 如果这份安装关联了系统共享服务，卸载时会先请求管理员授权，并移除该服务。需要授权的操作未获批准时，应用会保留。无法清理的密码或文件会列在卸载结果里，按提示处理即可。

### macOS

在“本机共享”确认共享已停止，并关闭“登录后自动共享”，再从“应用程序”删除 LL Remote。删除应用后，设置、钥匙串中的密码以及截图和录像仍会保留。需要手动清理时，可查阅“数据与隐私”中的文件位置和钥匙串条目。

可以在源码仓库的问题区（Issues）反馈。请说明操作系统、LL Remote 版本、操作步骤、预期结果，以及看到的提示或实际结果。附日志或图片前，请删除密码、访问令牌、主机地址、用户名和私密画面等信息。
