# 数据与隐私

LL Remote 把主机列表和设置保存在这台电脑上。应用没有云端账号、使用情况统计或自动错误上报。

## 密码和文件存在哪里

- LL Remote 会记住添加的主机名称、地址、端口、分组和你允许访问的文件夹。
- 选择保存密码后，macOS 使用钥匙串，Windows 使用系统凭据存储。Windows 系统共享服务的访问密码由 Windows 单独保管。
- 截图和视频保存在所选目录。收到的文件保存在接收端允许的目录。连接中断或应用异常退出后，磁盘上可能保留可恢复的录像或尚未收完的文件。
- 应用会在本机保存诊断日志。日志可能含有主机地址、端口、文件路径和使用时间。对外分享前请按需要删除敏感信息。

## 连接时会发送什么

连接后，对方的屏幕画面会传到你的电脑，你的键盘和鼠标操作会传到对方电脑。开启剪贴板同步后，剪贴板可能自动同步。上传文件会把所选文件发送给对方。

当前画面、操作、剪贴板及上传内容通过未加密的连接传输。密码用于验证谁能连接。请使用可信内网、可信 VPN 或加密隧道，并只与可信的设备共享。会话内容也可能包含你在其他应用中打开的资料。

Windows 安装包自带 WebView2，可离线安装需要的组件。之后 WebView2 的更新由 Microsoft 管理。系统权限、签名验证和系统凭据存储也由操作系统处理。

## 卸载、清理和备份

- 可以在“主机”中删除单个主机和对应的已保存密码。
- Windows 普通卸载会停止共享后台并移除登录自启动项，保留个人设置和密码。勾选“同时删除上述用户的设置、缓存和保存的密码”后，会额外清理确认页指定账户的数据。个人安装以安装账户为准，整机安装以发起卸载的账户为准。
- Windows 卸载会移除这份安装关联的系统共享服务，并尝试清理服务专用的密码和设置。无法清理的密码或文件会列在卸载结果中。
- macOS 将应用移到废纸篓后，个人数据和钥匙串里的密码仍会保留。
- 两个平台卸载时都会保留截图、录制和收到的文件。备份主机数据库只能保存主机列表和密码引用，恢复时可能需要重新输入密码。

## 查找文件和系统密码条目

需要手动备份、排查或清理时，可按以下位置查找。删除或替换数据库及共享目录前，请先停止共享并退出应用。

- **macOS 应用数据**位于 `~/Library/Application Support/LLRemote/`。主机数据库为 `hosts.sqlite3`，目录授权记录为 `file_access.json`。默认截图和录像在 `Artifacts/`，普通共享配置在 `Sharing/`。主应用日志位于 `~/Library/Logs/LLRemote/`。
- **Windows 应用数据**位于 `%LOCALAPPDATA%\LLRemote\`。其中 `Data\` 保存主机数据库和目录授权记录，`WebView\` 保存界面偏好和缓存，`Sharing\` 保存普通共享配置和后台副本，`Logs\` 保存主应用日志。默认截图和录像在 `Artifacts\`，收到的文件在 `ReceivedFiles\`。
- **Windows 系统共享服务**通常安装在 `%ProgramFiles%\LLRemote\Server\`，配置和状态保存在 `%ProgramData%\LLRemote\Server\`。
- 主应用日志文件名为 `LLRemote.log`。如果配置了 `VNC_LOG_DIR`，请到指定位置查找。共享后台的诊断记录位于共享数据目录。
- 系统密码条目包括 `LLRemote Host Password`（账户形如 `host:<ID>`）、`LLRemote Background Sharing`（账户为 `user-server`），以及 Windows 系统服务专用的 `LLRemote/Windows Service/RFB`。手动清理时，请先确认条目属于要清理的安装。
